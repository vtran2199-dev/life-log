# Life Log

A chronological, AI-assisted record of daily life, work, projects, decisions, learning, friction, wins, and memorable moments.

The repository is designed as a durable compression layer above disposable chats and day-to-day activity.

## Structure

- `daily/YYYY/MM/YYYY-MM-DD.md` — daily historical snapshots
- `weekly/YYYY/YYYY-Www.md` — weekly reconciliations synthesized from daily logs
- `monthly/YYYY/YYYY-MM.md` — monthly retrospectives synthesized from weekly logs
- `yearly/YYYY.md` — yearly retrospectives synthesized from monthly logs
- `prompts/` — versioned instructions used by scheduled or manual agents

## Principle

Raw activity can be chaotic and disposable. Important developments should be distilled into durable chronological files.

Daily files preserve what was known and experienced at the time. Higher-level summaries add hindsight without rewriting history.
